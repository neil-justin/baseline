## Rounding + honesty contract (unchanged and still locked)

- Half-down rounding, per factor: e.g. latestAir 60 → resume 4 (4.2 → 4); checkScore 40 →
  letter 2; a parse-failed run is not a run.
- An unmeasured factor never earns a painted zero and never displays a zero bar; the
  CHANNEL renders "—"/"not yet measured" exactly when nothing measured (the pre-walk
  dashboard already supports this copy).
- **Latest counts for the resume factor — RULED (2026-10-29 evening; ADR 0002 amendment
  3, superseding this section's earlier "best-run stays / NOT locked today" reading):**
  the resume factor reads the LATEST full attempt — re-running a worse file drops points;
  formula/calibration unchanged. The score's feed is built in `lib/db.ts` `getStudentView`
